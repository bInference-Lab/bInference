# Decisions

Every load-bearing decision about binference has a number. Decisions 0001 to 0097 were made before
the repository existed and are recorded as the log below, one row each. Every later decision is a
record file `docs/adr/NNNN-title.md` with four headings (Context, Decision, Consequences and
Alternatives), numbered from 0098 and written with the `write-adr` skill. A decision changes only
through a new one that supersedes or amends it: the old one keeps its text, and only its status
changes.

The rules these decisions set live in [ARCHITECTURE.md](ARCHITECTURE.md),
[ENGINEERING.md](ENGINEERING.md) and the [specs](specs/). Section 23 of ENGINEERING.md holds the
rules for decision records, and `pnpm check:adr` enforces them: the numbering, the four headings,
one row here per record, and the hashes in [decisions.lock.json](decisions.lock.json) that keep an
accepted decision's text from changing.
