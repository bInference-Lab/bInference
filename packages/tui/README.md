# @binference/tui

## Purpose

Terminal chat: `binference chat` talks with an agent in the terminal.

## API

| Export         | What it does                                                   |
| -------------- | -------------------------------------------------------------- |
| `ChatTerminal` | The terminal the chat runs in: its streams, raw mode and size. |

## Example

```ts
import type { ChatTerminal } from "@binference/tui";
```
